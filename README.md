https://ed-k.github.io/Radar-module-web-viewer/

There are many inexpensive radar modules that can detect the presence of people, or track cars or people in 2d. HLK makes many of these modules and they have demo software for Android, but it doesn't support my phone. This is an experiment to see if Claude (claude.ai) can make a viewer for a few different modules.
Yes, it worked, and it was very easy to do.
