Bluetooth settings (HLK-LD2451 only)

No modules connected

Connect a radar over USB serial and leave the model on Auto-detect. The page listens to what the module is already sending, works out which model it is, and only then enables that model's settings. You can connect several modules; each gets its own card. To see what a module's card looks like first, add demo data.
